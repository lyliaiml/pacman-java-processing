
# Pac-Man – Java Processing

## Présentation

Projet universitaire réalisé en décembre 2025.

Ce projet consiste à développer un jeu inspiré de Pac-Man en utilisant Java et l'environnement Processing.

L'objectif est de mettre en œuvre les mécanismes fondamentaux d'un jeu vidéo, notamment les déplacements, la gestion des collisions et le système de scores.

## Fonctionnalités

- Déplacements du personnage
- Gestion des collisions
- Système de scores
- Gestion de la logique du jeu

## Concepts informatiques abordés

- Programmation orientée objet
- Gestion des déplacements
- Détection des collisions
- Gestion des événements

## Technologies utilisées

- Java
- Processing

## Organisation du projet

- `src/` : code source
